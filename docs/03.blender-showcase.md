# Blender 手辦展示場景

`scripts/blender/figure_showcase.py` 會用 Blender（Cycles）把任一 GLB 模型放進預先設計好的展示場景並渲染。場景由腳本產生，不需要另外維護 `.blend` 檔。

所有場景都使用真實尺度（模型高約 15 cm）。對焦距離由 ray cast 打在模型臉部附近的多個點取中位數決定，所以焦點一定落在模型本體。

| 場景 | 說明 | 鏡頭 / 光圈 |
|---|---|---|
| `studio` | 商品型錄風格：米色無縫背景，沒有地台。大型柔光箱包覆打光、低反差、柔和陰影，整隻手辦清晰 | 85 mm / f/11 |
| `desk` | 晨光書桌：整個房間是 3D 搭建的。窗戶與實體百葉窗在畫面外左側一面斜放的牆上，陽光從左前方穿過百葉窗，在桌面與手辦上投出斜向條紋光影（不逆光，畫面內也沒有過亮的窗戶），加上淡淡的光霧。背景有牆面書架、檯燈與相框，桌上有鍵盤、疊書與盆栽、杯墊上的馬克杯。模型與背景由同一盞光照亮 | 35 mm / f/8 |
| `cafe` | 咖啡吧台：深色木吧台，模型左邊是盤子上的可頌與拿鐵；後方吧台有義式咖啡機、磨豆機、咖啡豆玻璃罐、牆上杯架、黑板與銅色吊燈，中度虛化。光線來自畫面外左側的窗戶與吊燈暖光 | 35 mm / f/8 |
| `records` | 黑膠角落：胡桃木邊櫃，左邊是薄型唱機（看得到唱片與唱臂），右邊一疊無字唱片封套；背景是落地的唱片櫃、三腳落地燈與邊櫃後方的綠葉，晚間暖光。鏡頭仰角比其他場景稍高（14°），讓唱片露出來 | 35 mm / f/8 |
| `fireplace` | 壁爐檯：木桌上有條紋玻璃杯裝的茶燭、松枝與兩顆松果；背景是石砌壁爐（木柴與真實火焰照片）、掛著燈串的花環、雪景窗（生成的雪夜照片）與布面沙發，冬夜暖光 | 35 mm / f/8 |

範例渲染：`docs/blender-showcase/`。

## 需求

- Blender 4.2 以上（以 5.2 LTS 測試）。不需要 GPU，CPU 即可。
- `desk`、`cafe`、`records`、`fireplace` 場景第一次執行時會下載素材並快取在 `.cache/`（不納入 Git）：
  - [Poly Haven](https://polyhaven.com)（CC0）：HDRI、木紋與石牆材質、盆栽、相框、沙發、抱枕與松樹模型（`sofa_03`）。
  - [NVIDIA SimReady Assets](https://huggingface.co/datasets/nvidia/simready-assets)（CC-BY 4.0）：可頌、杯子、馬克杯、玻璃罐、玻璃杯、茶燭等 OpenUSD 模型。

## 素材授權

`scripts/blender/textures/` 內的窗外雪景與火焰圖片由 gpt-image-2.5 生成，供 `fireplace` 場景使用。


`cafe`、`fireplace` 場景使用 NVIDIA SimReady Assets（CC-BY 4.0），公開渲染圖時需標註來源，例如：「部分道具模型：NVIDIA SimReady Assets, CC BY 4.0」。Poly Haven 素材為 CC0，不需標註。

## 使用方式

```bash
blender -b -P scripts/blender/figure_showcase.py -- \
  --model "models/holo/holo coffee.glb" --yaw -90 \
  --scene studio --out renders/holo_coffee_studio.png
```

`--` 之後的參數：

| 參數 | 說明 |
|---|---|
| `--model` | GLB / glTF 檔案路徑（必填） |
| `--scene` | `studio`、`desk`、`cafe`、`records` 或 `fireplace` |
| `--out` | 輸出圖片，`.png` 或 `.jpg` |
| `--yaw` | 讓模型正面朝向鏡頭的旋轉角度。標準 glTF（正面朝 +Z）用 `0`；holo coffee 正面朝 +X，要用 `-90` |
| `--focus-height` | 對焦高度（模型高度比例），預設 `0.72`，約為臉部 |
| `--res` | 解析度，預設 `1920x1280` |
| `--samples` | Cycles 取樣數，預設 256（含降噪）。快速預覽可用 32–64 |
| `--fstop` | 覆寫光圈，數字越小背景越模糊 |
| `--angle` | 覆寫鏡頭方位角，0 為正面 |
| `--height` | 模型高度（公尺），預設 0.15 |
| `--cache` | 下載素材的快取資料夾，預設 `.cache/` |
| `--save-blend` | 另外存一份組好的 `.blend`（貼圖會打包，檔案可能很大） |

## 備註

- 模型會自動縮放到指定高度、置中並放在地面／桌面上。
- 匯入後會套用 PVC 塗裝修正（略微加深貼圖、降低粗糙度、加一層薄 clear coat），避免只有單張貼圖的 GLB 在寫實光線下顯得平淡、偏白。
- `desk` 的太陽方向設定為從左前方穿過窗戶照到模型；百葉窗葉片角度會依太陽方向自動計算，擋掉約一半陽光，形成清楚的條紋。
- 色彩轉換使用 Khronos PBR Neutral，以保留貼圖原色。
- 在 4 核心 CPU 上，1920×1280、256 samples：`studio` 約 5 分鐘，`desk`（含光霧）約 20–30 分鐘，`cafe` 約 10–15 分鐘。
