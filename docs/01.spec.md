# 3D Gallery 功能規格

這份文件記錄網站目前提供的功能與基本使用方式。實際行為以程式碼為準。

## 模型瀏覽

- 左側為互動式 3D 模型預覽區。
- 拖曳可以旋轉模型視角。
- 滾輪可以平滑縮放，縮放中心固定在目前的觀察焦點。
- 手機與平板支援雙指縮放。
- 雙擊預覽區可以回到模型正面與初始距離。
- 模型載入期間會顯示進度條，標示已下載的百分比與 MB 數；下載完成、解析模型時顯示 `Preparing model`。檔案大小未知時改顯示來回移動的進度條與已下載 MB 數。
- 模型載入失敗時會顯示錯誤訊息。

## Preview 顯示控制

- 點擊左上角的 `Digital Collection` 可以隱藏 preview 內的標題、模型名稱與操作提示。
- 隱藏後只保留綠色圓點。
- 再次點擊圓點可以恢復文字。
- 右上角的全螢幕按鈕可以進入或離開全螢幕模式。
- 右上角的下載按鈕（太陽圖示下方）會下載目前顯示的模型 GLB 檔。
- 瀏覽器分頁圖示（favicon）每次開啟網頁會從 `public/favicons/01.png`–`16.png` 隨機挑一張。

## 模型清單

- 右側顯示目前資料夾內的模型。
- 使用 `Select folder` 切換不同模型資料夾。
- 點擊模型項目即可切換預覽模型。
- 目前選擇的模型會以綠色背景標示。
- 模型項目會顯示縮圖、名稱與所屬資料夾。
- 清單不提供合併所有資料夾的選項。

## 側欄

- 桌面版右側欄可以使用邊緣的圓形按鈕收合或展開。
- 在較窄的桌面與平板橫向寬度下，側欄預設收合以保留模型預覽空間。
- 手機版會完整顯示模型清單，不使用桌面版的收合狀態。

## Environment Settings

- 點擊 preview 右上角的太陽圖示開啟環境設定。
- 可以在 Studio、Studio HDRI、Beach、Desert、Forest、Interior、Night 之間切換環境光照。預設的 Studio 是程式產生的中性攝影棚（與 model-viewer 的 neutral 相同）。
- `Strength` 控制環境光照強度，預設 1.0。
- `Rotation` 控制環境光照方向。
- `Auto Rotate` 會持續旋轉環境光照，不會旋轉模型。
- Auto Rotate 啟用時，Rotation slider 會跟隨目前角度移動。
- `Look` 區塊可調整 Tone mapping（PBR Neutral／ACES Filmic）、Exposure、Shadow intensity、Shadow softness 與 Fill lights。詳見 [攝影棚外觀](03.studio-look.md)。

## 離線模型快取

- 正式部署後，已開啟過的模型會儲存在瀏覽器快取。
- 再次開啟同一模型時會優先使用快取內容。
- 第一次開啟模型仍需要網路連線。

## 響應式顯示

- 桌面版使用左右雙欄配置。
- 小於 1024px 時改為上下排列。
- Mobile preview 使用固定的響應式高度，模型清單顯示在 preview 下方。
