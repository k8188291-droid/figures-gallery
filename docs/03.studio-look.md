# 攝影棚外觀（Studio look）

模型瀏覽器預設改用與 Google `<model-viewer>` 3.5.0 相同的「neutral」打光，仍然是純 Three.js，程式在 `src/studioLook.js`。對照設定為：

```html
<model-viewer environment-image="neutral" tone-mapping="neutral" exposure="1.05"
  shadow-intensity="0.7" shadow-softness="0.9">
```

## 內容

- **Studio 環境**：程式產生的中性攝影棚 IBL，房間、方塊、面光源與強度直接取自 model-viewer 的 `EnvironmentScene.ts`；先拍成 256px cube map，再做同樣的 sigma 0.04 模糊，最後轉成 PMREM。不需要下載圖檔。
- **PBR Neutral 色調映射**：`THREE.NeutralToneMapping`（Khronos PBR Neutral）。使用 Studio 環境時，曝光值會再乘 1.3，與 model-viewer 的處理相同；使用全景圖時不乘。
- **只用 IBL**：model-viewer 沒有額外燈光，所以原本的 Hemisphere／Directional 補光預設關閉。
- **接觸陰影**：從模型底部往上拍深度、模糊後貼在模型下方的平面。大小依模型包圍盒自動調整，換模型時重新計算。陰影與光線方向無關，旋轉視角或環境都不需要重算。VR 與展示桌預覽中會隱藏（展示桌有自己的台座，模型也可以拿起來）。

## 環境面板新增的選項

| 選項 | 預設 | 說明 |
| --- | --- | --- |
| Surrounding → **Studio** | 預設 | 程式產生的中性攝影棚。原本的 studio 全景圖改名為 **Studio HDRI**，其他全景圖照舊。 |
| Strength | 1.0 | 環境光強度（`scene.environmentIntensity`）。原本預設 1.5，為了與 model-viewer 一致改為 1.0。 |
| Rotation／Auto Rotate | 0° | 與原本相同，Studio 環境也能旋轉。 |
| Tone mapping | PBR Neutral | 可切換為 ACES Filmic（舊版外觀使用的映射）。 |
| Exposure | 1.05 | 曝光值，對應 model-viewer 的 `exposure`。 |
| Shadow intensity | 0.7 | 陰影濃度，對應 `shadow-intensity`；0 會關閉陰影。 |
| Shadow softness | 0.9 | 陰影柔和度（0–1），對應 `shadow-softness`；越柔和解析度越低，成本也越低。 |
| Fill lights | 關 | 開啟原本的 Hemisphere 1.2 + Directional 2.4 補光。 |

要接近舊版外觀：Surrounding 選 Studio HDRI、Tone mapping 選 ACES Filmic、Exposure 1.1、Strength 1.5、開啟 Fill lights、Shadow intensity 0。

## 在程式中使用

```js
import { STUDIO_DEFAULTS, applyStudioLook, createNeutralEnvironment } from './studioLook'

const look = applyStudioLook(THREE, renderer, scene, { ...STUDIO_DEFAULTS, lights: [hemiLight, keyLight] })
scene.environment = createNeutralEnvironment(THREE, renderer, pmrem).texture
look.shadow.fit(model)                 // 模型載入後
look.shadow.render(renderer, scene)    // 每幀 render 前；只有需要時才會重畫
look.update({ toneMapping: 'aces', exposure: 1.1, shadowIntensity: 0 })
```

`createContactShadow(THREE, { intensity, softness })` 也可以單獨使用。

## 已知差異

- 以同一模型、同一鏡頭比較，模型區域的平均色差小於 1（0–255），陰影區域約 0.2。剩下的差異主要是 Three.js 版本不同（model-viewer 3.5.0 內含 r163，本站使用 r179）造成的邊緣抗鋸齒。
- 本站背景是深色，接觸陰影在深色背景上幾乎看不到；在淺色背景上才明顯（model-viewer 也一樣）。
- VR／展示桌場景同樣改用 Studio IBL，地板與台座會比以前稍亮。
